# Memoir

An interactive web application designed for personal reflection, featuring a mood-tagged journaling system, real-time search, category filtering, and an integrated music playlist.

## Features

* **Journaling System:** Create, view, and delete personal notes with automated timestamp tracking.
* **Mood Tagging:** Categorize entries using mood options (**Joyful**, **Gloomy**, **Nostalgic**, and **Frustrated**), complete with custom color-coded badges and icons.
* **Real-time Search & Filtering:** Instantly filter entries by mood or search through note titles and content as you type.
* **Interactive UI & Animations:** Smooth transitions, responsive grid layouts, modal overlays, and hover-glow effects on cards.
* **Music Player Integration:** Seamlessly switch to the music section to play, pause, and browse audio tracks.
* **Persistent Storage:** Automatically saves and loads your journal entries using browser LocalStorage.

## Tech Stack

* **Markup & Styling:** HTML5, CSS3 (Grid, Flexbox, Custom Effects)
* **Scripting:** JavaScript (ES6+, DOM Manipulation, LocalStorage API)
* **Icons:** FontAwesome
